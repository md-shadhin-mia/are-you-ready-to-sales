# Rule: Isolated Feature Branching
Always ensure you are working on a dedicated feature branch before modifying any source code or installing packages.

## Guidelines:
1. NEVER commit directly to the `main` or `develop` branches.
2. When assigned a feature, optimization, or bug fix task, check out a new branch formatted as `ai/feature-name` or `ai/bugfix-name`.
3. Before writing code, run local static analysis or syntax checks to ensure baseline project integrity.
4. If a terminal execution policy requires permission, look for the 'request review' indicator in Quick Settings.
